User guide

Start with real traces

Run the local server and open the address printed in the terminal. The bundled DUET R2R unseen-validation collection loads automatically: 2,349 episodes. Use Import JSON / JSONL for another collection. All analysis runs locally.

Retrieve a case

Choose a cohort row in Behavior Cohort Fingerprint. Representative selects its nearest visible real episode to the fixed centroid. Severe failure selects the greatest valid outcome severity. Boundary case selects the smallest own-versus-other centroid margin. Disabled cards indicate missing eligible cases.

Inspect a decision

Opening an episode selects its first verified geometric conflict, otherwise its greatest negative distance progress, otherwise the first decision. Click a route point or ribbon column to update the route, evidence summary, candidates, and alternative view together.

Read the evidence

Blue indicates executed behavior, teal the selected movement, green the reference, and orange the inspected alternative or an unlogged global choice. The ribbon separates local probability coverage from global entropy. Hatching indicates probability mass absent from the exported local table.

Compare an alternative

Click a candidate row. Geometry only displays an ideal shortest continuation using the complete static graph. It is not a policy rerun. The supplied data contain no candidate images or controlled rollouts; missing evidence remains unavailable.

Save and restore

Pin one episode to compare it with another. Save notes for the current episode and step, then export the analysis record. Keep the trace file separately. Restore the record after loading the same source data; mismatched fingerprints are rejected.

Paper figures

View titles contain names only. Letter labels in manuscript figures are added after capturing the live interface. The SVG buttons export individual vector views.

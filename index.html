Case selection and clustering definitions

Six default features: mean/peak entropy, full-path revisit ratio, log(1 + decisions), unlogged-choice ratio, and local probability mass. Coverage also affects grouping. We standardize features, impute missing values with reference medians, and use deterministic k-means. Outcome metrics and failure labels are excluded by default.

Representative selects the visible episode nearest its fixed cohort centroid. Severe failure maximizes equally weighted NE/SPL/nDTW severity among valid failures. Boundary minimizes other-centroid minus own-centroid distance. Unavailable choices are disabled; selectors may return the same episode.
